# Licencias de recursos de terceros

## Tipografías
| Fuente | Uso | Licencia |
|---|---|---|
| Zilla Slab (Mozilla) | Títulos | SIL Open Font License 1.1 |
| Karla (Jonny Pinhorn) | Texto | SIL Open Font License 1.1 |
| IBM Plex Mono | Datos y aretes (solo prototipo web) | SIL Open Font License 1.1 |

Los archivos `.ttf` en `android/app/src/main/res/font/` son el subconjunto latino de estas fuentes. La licencia OFL permite usarlas, incluirlas en la app y redistribuirlas.

## Fotos de razas
Los créditos de cada foto están en `fotos-razas/creditos.csv` y se muestran en la ficha de cada raza.
