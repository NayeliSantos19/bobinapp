BOBINAPP API

Backend de Bobinapp: app Android de gestión ganadera que funciona sin señal, con genealogía, alertas y escáner de razas por foto.

Comprobando…
Código en GitHub /api/salud /api/razas

Qué hace

Sincroniza los teléfonos de cada finca (cola local + last-writer-wins con cursor del servidor), guarda las fotos de los animales, identifica razas con un modelo de visión y recibe analítica de uso anónima.

Node.js 22 · Express · PostgreSQL 16 · zod · pruebas de integración contra PostgreSQL real en cada push.

Rutas

GET /api/saludEstado de la API y de la base de datos
GET /api/razasCatálogo de 33 razas bovinas
POST /api/fincasCrea una finca y devuelve su token una sola vez
POST /api/sync/pushSube animales y eventos (token)
GET /api/sync/cambiosDescarga cambios desde un cursor, paginado (token)
PUT · GET /api/fotos/:idFoto de un animal, verificada por su firma real (token)
POST /api/identificarIdentifica la raza a partir de una foto (token)
POST /api/telemetriaEventos de uso anónimos, sin token y sin guardar la IP

Plan gratuito de Render: si la API estuvo inactiva, la primera petición tarda cerca de un minuto en despertar.
